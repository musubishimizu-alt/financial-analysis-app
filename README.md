# 有価証券報告書 財務分析＆クイズ Webアプリケーション
(EDINET Financial Analyzer & Securities Report Quiz)

国内上場企業が金融庁に提出した最新の**有価証券報告書（EDINET開示データ）**に基づき、投資家が企業分析で重要視する主要財務指標（**自己資本比率・ROE・ROIC・PBR・PER・ROA・売上高営業利益率**の7指標）を自動計算・可視化し、有報データをもとにした3択クイズを出題するWebアプリケーションです。

---

## 主な機能

### 1. 企業財務分析（検索＆サジェスト）
- **部分一致インクリメンタルサーチ**: 企業名（漢字・ひらがな・カタカナ）、英語名、証券コードで即時絞り込み。
- **代表的企業のクイック選択**: トヨタ、任天堂、ソニー、キーエンス、ファーストリテイリングなどの代表銘柄にワンタップアクセス。
- **EDINET直接リンク**: 金融庁EDINETの該当書類ページへの直リンクを常時配置。

### 2. 投資家が重視する主要財務分析指標の計算＆根拠明示（7大指標）
- **PBR (株価純資産倍率)**: 解散価値対比での株価評価・東証PBR改革の焦点（1倍割れ判定）
- **PER (株価収益率)**: 利益対比での株価評価・投資回収年数・市場期待度
- **自己資本比率 (Equity Ratio)**: 財務健全性、倒産リスクの低さ
- **ROE (自己資本利益率 - Return on Equity)**: 株主目線での資本効率、収益力（伊藤レポート8%以上）
- **ROIC (投下資本利益率 - Return on Invested Capital)**: 本業の稼ぐ力と資本コスト（WACC）対比
- **ROA (総資産利益率 - Return on Assets)**: 会社全体の資産活用効率
- **売上高営業利益率 (Operating Margin)**: 本業の競争優位性、モート（堀）
- **徹底した根拠開示**:
  - 各指標の「定義式」
  - 実際の決算数値をあてはめた「具体的な計算式」
  - 計算に使った「開示勘定科目名」
  - 有価証券報告書内での「掲載セクション」および「具体的なページ番号」（主要な経営指標等の推移、連結貸借対照表、株式等の状況など）

### 3. 有報 財務クイズチャレンジ（3択問題）
- 上場企業の中からランダムに1社および財務指標（PBR・PER・ROE等）を自動選定。
- 有報から抜粋した決算数値（ヒント）をもとに、正しい財務指標を3択から回答。
- 回答後、即座に正解・不正解を判定し、詳細な計算プロセス、有報の掲載箇所、投資判断上のポイントを解説。
- スコア（正解数・連続正解ストリーク）の記録。
